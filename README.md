# 百年广大 · 时光漫游

> 广州大学第二十二届学术科技节 · 网页设计大赛 · **方向二｜交互体验网页**
> 主题：**百年广大**

---

## 一、作品简介

《百年广大 · 时光漫游》是一款以「广州大学建校 100 周年」为主题的沉浸式交互体验网页。作品以深蓝星空与鎏金交错的东方美学为基调，将「回望峥嵘校史、定格校园地标、点亮祝福心愿、展望百年未来」融为一体，让浏览者在滚动、点击、拖拽之间，完成一场穿越百年的数字漫游。

围绕「方向二 · 交互体验网页」的要求，作品集成了七类核心交互：

| 章节 | 交互形式 | 说明 |
| --- | --- | --- |
| 壹 · 百年纪事 | **时间轴交互** | 可拖拽 / 滚动的横向时间轴，串联 1927—2027 九大历史节点 |
| 贰 · 校园漫游 | **虚拟校园漫游** | 以真实航拍图为底，点击金色光点聚焦地标实景，支持「自动漫游」 |
| 叁 · 校园掠影 | **校园实景** | 图书馆、演艺中心、体育馆等 8 张校园实景照片，点击可放大 |
| 肆 · 百年祝福 | **祝福墙** | 写下对广大的祝福，化作一盏金色心愿灯缓缓升起 |
| 伍 · 数据画卷 | **数据可视化** | 数字滚动 + 柱状/环形 Canvas 图表，展示真实的学科、学位与招生专业数据 |
| 陆 · 拾忆游戏 | **游戏化探索** | 限时拾取金色记忆碎片，集齐「博学笃行 与时俱进」八字校训彩蛋 |
| 柒 · AI 寄语 | **AI 创意** | 「AI 灵感引擎」随机织就专属百年寄语，打字机式呈现 |

## 二、技术实现

- **纯原生 HTML / CSS / JavaScript**，零外部依赖、零框架，加载迅速、运行稳定、可离线打开；
- **响应式适配**：桌面端与移动端（含手机菜单）双端自适应；
- **Canvas 2D**：粒子星尘背景、数据图表可视化；
- **SVG**：百年版徽描边动画；校园航拍图叠加交互热点（点击聚焦地标）；
- **DOM + localStorage**：祝福墙心愿灯动画，祝福在本机持久化保存；
- **IntersectionObserver**：滚动揭示动画、图表/数字按需触发；
- **Pointer Events**：时间轴拖拽、移动端触控手势。

## 三、运行方式

1. 直接双击 `index.html` 用浏览器打开即可（推荐 Chrome / Edge 最新版）；
2. 或部署到任意静态服务器（如 VS Code Live Server）获得最佳体验；
3. 祝福墙会使用浏览器 localStorage 保存你写下的祝福（仅本机可见）。

> 项目目录结构：
> ```
> 百年广大-交互体验/
> ├── index.html        # 页面结构
> ├── css/style.css     # 视觉样式
> ├── js/app.js         # 交互逻辑
> ├── images/           # 校园实景图片
> ├── README.md         # 作品简介（本文件）
> └── .nojekyll         # GitHub Pages 部署配置
> ```

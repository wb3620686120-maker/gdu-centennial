# 百年广大 · 时光漫游

> 广州大学第二十二届学术科技节 · 网页设计大赛 · **方向二｜交互体验网页**
> 主题：**百年广大**

---

## 一、作品简介

《百年广大 · 时光漫游》是一款以「广州大学建校 100 周年」为主题的沉浸式交互体验网页。作品以深蓝星空与鎏金交错的东方美学为基调，将「回望峥嵘校史、定格校园地标、聆听广大之声、展望百年未来」融为一体，让浏览者在滚动、点击、拖拽之间，完成一场穿越百年的数字漫游。

围绕「方向二 · 交互体验网页」的要求，作品集成了六类核心交互：

| 章节 | 交互形式 | 说明 |
| --- | --- | --- |
| 壹 · 百年纪事 | **时间轴交互** | 可拖拽 / 滚动的横向时间轴，串联 1927—2027 九大历史节点 |
| 贰 · 校园漫游 | **虚拟校园漫游** | 手绘风格 SVG 校园地图，点击光点聚焦地标，支持「自动漫游」镜头巡游 |
| 叁 · 声音地图 | **声音地图** | 用 Web Audio API 程序化合成六种校园之声，配实时频谱波形 |
| 肆 · 数据画卷 | **数据可视化** | 数字滚动 + 柱状/环形 Canvas 图表，展示真实的学科、学位与招生专业数据 |
| 伍 · 拾忆游戏 | **游戏化探索** | 限时拾取金色记忆碎片，集齐「博学笃行 与时俱进」八字校训彩蛋 |
| 陆 · AI 寄语 | **AI 创意** | 「AI 灵感引擎」随机织就专属百年寄语，打字机式呈现 |

## 二、技术实现

- **纯原生 HTML / CSS / JavaScript**，零外部依赖、零框架，加载迅速、运行稳定、可离线打开；
- **响应式适配**：桌面端与移动端（含手机菜单）双端自适应；
- **Canvas 2D**：粒子星尘背景、数据图表、音频波形可视化；
- **SVG**：校园地图与百年版徽，支持 viewBox 平滑缩放「镜头」动画；
- **Web Audio API**：钟声、翻书、流水、鸟鸣、琴音、掌声等全部由程序化合成，无需外部音频文件；
- **IntersectionObserver**：滚动揭示动画、图表/数字按需触发；
- **Pointer Events**：时间轴拖拽、移动端触控手势。

## 三、运行方式

1. 直接双击 `index.html` 用浏览器打开即可（推荐 Chrome / Edge 最新版）；
2. 或部署到任意静态服务器（如 VS Code Live Server）获得最佳体验；
3. 声音需在页面内点击「播放」类按钮触发（浏览器自动播放策略），首次点击后即可正常发声。

> 项目目录结构：
> ```
> 百年广大-交互体验/
> ├── index.html        # 页面结构
> ├── css/style.css     # 视觉样式
> ├── js/app.js         # 交互逻辑
> └── README.md         # 作品简介（本文件）
> ```

## 四、原创与说明

- 本作品为参赛原创：页面结构、视觉设计、交互逻辑、程序化音效均由代码从零实现；
- 校园地图为**艺术化示意**，非精确地理测绘；校史时间轴与数据图表均整理自公开资料（广州大学官网《学校简介》2026 年 9 月更新、广州大学图书馆官方简介）；
- 校训「博学笃行 与时俱进」等元素为校园公共文化符号，仅作主题表达使用。
